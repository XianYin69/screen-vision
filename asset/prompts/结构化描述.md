# 结构化描述（vision_descriptor v2 专用）
只输出一个 JSON 对象，不要解释、不要代码块围栏。对截图中每个可见对象：

```json
{"objects":[{"id":1,"type":"button","label":"确定","confidence":0.9,
"bbox_norm":[0.07,0.5,0.22,0.1],"z_order":3,
"depth_cues":{"occludes":[2],"occluded_by":[],"baseline_y_norm":0.6,"relative_size":0.02},
"actionable":true,"action_hint":"click","affect":null,"emotion":null}]}
```

## 规则
- `type` 枚举：button|input|text|icon|image|list|dialog|checkbox|link|person|face|qr|captcha|other。
- `bbox_norm` = [x,y,w,h]，0~1，相对本图左上角；拿不准的对象宁可不列。
- 前后关系：只按**遮挡轮廓中断 / 基线 y / 相对大小**判断，禁止按明暗猜深度；
  窗口间前后由脚本按 z-order 定，你只需给窗口内 `depth_cues.occludes`。
- `affect`/`emotion`：仅人脸（face/person）或内容语义（表情、评价文字）可填，
  且 `affect.domain` 标 `face|content`；UI 控件、验证码一律 `null`，不得编造。
- 敏感值（密码/令牌/密钥/验证码）：`label` 只报类别（如「密码输入框」），不复述原文。
