# 窗口截取原理

## 枚举
`pygetwindow` 封装 Win32 `EnumWindows`，返回顺序即 z-order（顶层在前），故 `sw.py list`
的 `index` 可直接喂给 `capture --index`，无需另查句柄。每窗口给 `title / _hWnd /
left,top,width,height`；`box = [left, top, left+width, top+height]`。

## 截取
本机 `mss`、`pywin32` 不可用，采用 `PIL.ImageGrab.grab(bbox=...)`：
本质是**桌面坐标区域的位图拷贝**，不是 `PrintWindow`。因此——

- 目标必须**可见且不被遮挡**：截的是屏幕上那块矩形，叠在它上面的窗口会一起进来；
- 最小化窗口无桌面像素 → 得到空图/黑图。本技能不做静默还原：`sw.py capture` 需显式
  `--minimize-safe`（`ShowWindow(SW_RESTORE)` + `SetForegroundWindow` + 0.35s 等待）；
  `recognize.py ask` 遇最小化直接报错退出（错误信息指向 `--minimize-safe`）。
- 尺寸 < 20px 的窗口判为异常并中止，不产出占位图（见 [红线约束](../resistance/红线约束.md)）。

## 坐标 clamp
实测 SMSH 窗口 `bbox=(49,-7,1714,1074)`：标题栏顶边超出主屏上沿，`top=-7`。
`ImageGrab` 的 bbox 默认按主屏虚拟坐标裁剪，负值会被拒绝或截出空白带 →
统一 `t = max(0, top)`，故出图高度 = `height - |top|`，比窗口名义高度略小。
需要完整跨屏画面时加 `--all-screens`（`ImageGrab` 走虚拟屏幕，可含负坐标）。
