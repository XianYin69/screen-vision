# 网关视觉调用

## 配置来源（唯一）
只读 `<SMS_HOME>\config\config.json` 的 `llm_gateway` 段：
`{enabled, base_url, api_key, model, max_tokens, timeout}`。
`SMS_HOME` 取环境变量，缺省 `%LOCALAPPDATA%\SMS`。
**不复制、不重建、不回写**该配置；缺 `base_url` 即报错退出（见
[依赖与产物约束](../resistance/依赖与产物约束.md)）。

## 请求
`POST {base_url}/chat/completions`，OpenAI 兼容 + Bearer：

```
{"model": cfg.model 或 --model,
 "max_tokens": --max-tokens(默认 800),
 "messages": [{"role":"user","content":[
    {"type":"text","text": <prompt>},
    {"type":"image_url","image_url":{"url":"data:image/png;base64,<b64>"}}]}]}
```

图以 base64 data URL 内嵌，无需外网图床。实测 `model=auto` → HTTP 200 且识别正确
（1665x1081 窗口图）。

## 失败语义
- 非 200：打印状态码 + 响应前 300 字，`exit 1`，**不重试**（防重试风暴）；
- 超时：沿用 `cfg.timeout`（默认 120s），由 requests 抛错即终止；
- 网络不通（网关未起）：同上直接报错，提示先确认 SMS 网关在跑。

## 出参
`{reply, usage, model, window, image, prompt}` — 结构见
[recognize_output.schema.json](../schemas/recognize_output.schema.json)。

## 敏感内容
回复若含密码/令牌/私钥，只报**类别与位置**，不复述原文；规则见
[敏感信息约束](../resistance/敏感信息约束.md)。
