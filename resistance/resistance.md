# resistance（约束库 / 兜底）

本目录是 screen-vision 不可逾越的规则。任何调用先满足此处，再谈功能。

## 清单
- [红线约束](红线约束.md)：失败语义——报错即停，禁止重试风暴与占位黑图。
- [依赖与产物约束](依赖与产物约束.md)：不自动装包；产物只落缓存目录或 `--out`。
- [敏感信息约束](敏感信息约束.md)：密码/令牌只报类别不复述；配置只读不回写。

## 兜底降级顺序
1. 缺依赖 → `deps.require` 打印包名 + 手动安装建议，`exit 2`；
2. 找不到/歧义窗口 → `winscan.die` 给 `sw.py list --filter` 下一步命令，`exit 1`；
3. 截图异常（最小化、尺寸<20px、bytes=0）→ 中止，不送网关（省 token 且防幻觉）；
4. 网关非 200 / 超时 / 配置缺失 → 打印原文片段，`exit 1`，不重试、不改配置；
5. DPI 模式非 `per-monitor-v2` → 仍出图，但如实标 `dpi_mode`，由调用方决定是否重截。
