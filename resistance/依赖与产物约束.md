# 依赖与产物约束

## 依赖（Python 3.14 实测）
- 可用：`pygetwindow`、`PIL.ImageGrab`(pillow)、`requests`、`numpy`。
- 不可用：`mss`、`pywin32` —— 不得为此临时 pip 安装，也不得写「自动装包」逻辑。
- 任何 import 失败：`deps.require([...])` 打印缺哪个包 + `python -m pip install <包>`
  建议 + 退出码 2。**本技能永不自动执行 pip**，安装与否由用户拍板。
- 新增依赖前先确认：能否用现有四件套 + `ctypes` 标准库解决（DPI 与还原窗口即走 ctypes）。

## 产物
- 截图/识别中间图**只**写 `%LOCALAPPDATA%\SMS\cache\screen_vision\`
  （由 `deps.cache_dir()` 生成，`SMS_HOME` 优先），或调用方显式 `--out`。
- 禁止写技能目录（`C:\Users\User\AppData\Local\SMS\skills\screen-vision\`）：
  运行时 PNG、日志、缓存、`__pycache__` 之外的一切临时物。
- 技能目录只允许源码与文档；`tmp/`、IDE 目录、`__pycache__/` 已在 `.gitignore`。
