# 红线约束（失败语义）

## 必须
- 找不到窗口、标题歧义、图片不存在、窗口最小化、尺寸异常、`bytes=0`：**立即**
  `exit 1` 并把原因打到 stderr，附上可直接执行的下一步命令。
- 一次调用只做一次尝试：截取一次、网关请求一次。
- 错误信息含具体对象（窗口标题、bbox、状态码），便于调用方定位。

## 禁止
- **重试风暴**：不得循环重试截取或网关（失败即停，由人/上层决定）。
- **占位黑图**：不得为「不崩溃」而生成空白图、纯色图、上一次的旧图继续送识别。
- 静默吞异常（`except: pass`）后返回成功。
- 用 `--minimize-safe` 之外的方式自动还原/激活窗口（会抢前台焦点）。
- 在技能目录写运行时产物（见 [依赖与产物约束](依赖与产物约束.md)）。
- 把「模型没答上」当「截图失败」——先按 [DPI与多屏注意](../knowledge/DPI与多屏注意.md)
  的自检顺序隔离两段。
